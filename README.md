# Logistic Regression from Scratch

This project demonstrates a simple implementation of **Logistic Regression** built entirely from scratch in Python.  
It includes:
- A Python script (`logistic_regression.py`) that defines the model and training process.
- A Jupyter Notebook (`logistic_regression.ipynb`) where the model is applied to a dataset for experimentation and evaluation.

## 🚀 Features
- Gradient descent optimization
- Sigmoid activation function
- Binary classification
- Evaluation metrics (accuracy, loss visualization)

## 📂 Files
- `Log_Reg.py` → Core implementation of logistic regression
- `Implementing Logistic Regression.ipynb` → Dataset loading, training, and results
